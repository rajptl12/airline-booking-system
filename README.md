# Airline Booking System

This is a premium flight and hotel booking system built with [Next.js](https://nextjs.org) and Tailwind CSS.

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features
- Dynamic Flight and Hotel search.
- Responsive UI built with Tailwind CSS.
- Modern layout with interactive widgets.
